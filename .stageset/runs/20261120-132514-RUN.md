## Result

PASS for the deployment and model checks. FAIL for the 32-client HTTP gate.

## Facts

- A Modal T4 container runs the app with `pocket-tts==4.0.1` and torch 2.15.0.
- Cold boot to `/health` 200 is 17.3 s. Prewarm is 255.0 ms.
- `/tts` and `/tts/stream` serve real WAV and PCM audio. Profile `v1` works.
  An unknown profile returns 400.
- Direct `BatchedStream` on Modal T4 at B=32: first emit p50 33.7 to 45.3 ms.
  Wall is 1.1 to 1.2 s. The model path is fast.
- The public Modal URL adds about 188 ms per request from this Kaggle host.
- The 32-client HTTP gate fails on Modal: client p95 2151 ms.
- The server-side cause is batch arrival spread, not model compute.
  Batch size p50 is 14. Batch spread p95 is 1380 ms. Batch wait p95 is 1481 ms.
  Small early batches run serially. Late jobs wait for the prior batch.
- `modal run` on a function in the same app name as a deployed app stops that
  deployment. Use a separate dev app for helpers.

## Guesses

- The spread comes from the Modal public proxy and HTTPS ingress, not from token
  chunking. Chunk time p95 was 2.9 ms in the warm run.
- Continuous batching or an in-container prober will be needed to reach the
  350 ms gate under real ingress.

## Assumptions checked

- A-30 (row-based admission is needed): not proven. Batch size p50 was 14, so a
  row-count rule alone cannot fill a 224-row batch when arrivals spread.
- A-31 (fixed probe client limit): CONFIRMED. The probe reads `ARSENAL_LOAD_LIMITS`.

## Tried

- `modal run ...::build_assets` to build the voice cache and profiles into the
  `arsenal-tts-cache` Volume. PASS.
- `modal deploy` then `/health`, `/tts`, and profile `/tts`. PASS.
- `direct_bench` at B=32. PASS. Model path is fast.
- External 32-client probe. FAIL at p95 2151 ms.
- Ran the probe 8, 16, 24, and 32 clients. All fail with p50 1.6 to 1.9 s.
- Tried a 50 ms batch window. It was worse (p50 934 ms).
- Tried a 64-thread chunk pool. Chunk time p95 dropped to 2.9 ms, but the gate
  still failed. The spread remains.
- Stopped the app with `modal app stop ... -y`.

## Open question for planner

Do we accept the network floor, or do we plan continuous batching? The model
path is fast. The limit is ingress spread plus head-of-line batching.
