## Result

## Facts

- In one process, the shorter voice is faster. Median first chunk: 4.0 s 163.8 ms, 3.0 s 145.2 ms, 2.0 s 130.0 ms.
- The ranking follows the prefix width: 51, 39, and 26 frames.
- The earlier random probe ran each config in a separate process. That test showed the opposite order.
- The cause of the earlier gap is measurement bias between processes, not model behavior.

## Guesses

- Model load, CUDA context setup, and GPU clock state differ between subprocess runs.
- The first burst in a fresh process pays a warmup cost that the shared stream does not pay.

## Assumptions checked

- A-19: random order removes run-order bias. REFUTED across processes. Order is not the only bias. Process start state is also a bias.
